# 录屏音频预览（本地开发版，未发布）

1. 在录屏设置中选择麦克风和系统声音输入。
2. 打开录屏面板后自动检测所选音源，无需测试按钮。青色为麦克风，紫色为系统声音，系统双声道分别显示 L/R。
3. 波形表示当前输入的峰值包络，右侧是峰值 dBFS；静音时变为平线，接近满幅时显示红色过载提示。
4. 录制前可以切换设备；旧设备关闭后才会打开新设备。选「不录制」不打开对应输入。
5. 点击开始录制会先释放预览设备。正式录制直接从实际录音回调采样，不重复打开监听设备。
6. 开始后设置窗口最小化到任务栏，不显示悬浮条。在任务栏恢复窗口即可查看实时视频、音频波形并暂停/停止。暂停时仍可观察音频输入，但不写入录音。
7. 录制及暂停时锁定音源、录制目标、分辨率、帧率、光标/画笔、保存目录等设置。停止后解锁。录制时关闭窗口只会最小化，不会中断录制。

## 隐私和限制

- 音频检测仅在打开录屏设置后启动，不生成音频文件，也不外放声音；未录制时关闭/隐藏设置会释放设备，退出应用时等待设备释放。
- 测试与当前录音采用相同的设备、44100 Hz 采样率和通道数（麦克风单声道，系统最多双声道）。
- 「系统声音」沿用现有立体声混音/虚拟输入设备；不新增任意扬声器 WASAPI 回环或浏览器独立音轨捕获。
- 输入波形不能证明最后的混音和视频封装正确，仍建议录制几秒并回放检查；不保证所有硬件兼容。
- 显示设置窗口时，窗口可能进入屏幕录制画面。
- 单独窗口模式只使用目标窗口捕获，不回退到桌面区域截图；关闭、最小化或捕获失败时不会改录其他窗口。连续五秒无画面会停止并提示保存已有部分。不支持的硬件加速窗口可能无法捕获，需要实际验证。
- 全屏/屏幕模式会录入该屏幕上显示的窗口和任务栏；不会自动排除录屏设置窗口。
- 窗口列表保留完整的 Windows 窗口标题，悬停可查看全文。浏览器管理器内未同步到系统标题的内部备注无法自动识别。

## 验证

自动化测试使用合成音频，不访问用户实际麦克风。覆盖单/双声道、不因反相抵消、静音/过载、设备失败清理、设备切换、隐藏停止预览、预览到录制的交接、任务栏最小化/恢复、设置锁定、暂停保存、重复提交保护和 MP4 解码。另有单窗口禁止回退桌面及捕获失败保留录像的回归测试。
