# 录屏 GUI 测试路径误判修复（2026-09-07）

## 失败与原因

v1.0.15 的 GitHub Actions 运行 34151369567 在录屏 GUI 测试中失败，尚未进入打包和发布。
失败断言直接比较保存对话框返回路径与预期路径的文本表示。
该运行的 Windows 临时目录使用 `C:/Users/RUNNER~1/...` 短路径。

在独立 Python 3.12 环境中，将临时目录切换为真实的 Windows 8.3 别名后复现了同一断言失败：
测试预期包含 `TEST-T~1`，Qt 返回 `.test-temp`，两者指向同一目录。

## 修复边界

- 仅修改 `tests/recorder_gui_smoke.py` 的两处保存路径断言：比较 `Path.resolve()` 的结果。
- 保留短路径输入，确保仍覆盖 Qt 对路径的转换。
- 添加断言诊断信息，失败时打印实际路径、预期路径及对话框目录。
- 不修改录屏功能，不禁用测试，不放宽目标文件要求。
- 仍验证实际保存路径、仅启动一个保存任务、界面响应、文件大小及 MP4 解码。
