## 环境与限制

- 自动测试：本机 Python 3.12。
- 窗口测试：本地便携版使用的 Python 3.14/Qt 运行环境，offscreen 模式。
- 发布流水线将使用固定的 Python 3.12.10 和 requirements-build.txt，再运行上述三组窗口测试；任意一项失败即停止发布。
- 未在本轮重新验证真实 YouTube 网络、登录/地区限制、全部视频编解码器、真实麦克风/系统声音、多显示器/DPI组合或 Windows 重启后的自启动。
- 没有实际运行用户电脑的清理任务，没有改动个人便签、待办、闹钟或其他设置。
- 新的 Windows 安装包与下载产物尚需由 CI 构建后验收，不能把本地源码测试当作发布产物验证。

## 复现命令

在安装了项目依赖的 Python 环境中运行：

```powershell
python -B -m unittest discover -s tests -v
$env:QT_QPA_PLATFORM = 'offscreen'
python -B tests/application_gui_smoke.py
python -B tests/screenshot_cleaner_gui_smoke.py
python -B tests/recorder_gui_smoke.py
```

各窗口测试在独立进程中运行。请不要把这些模拟结果解读为真实桌面、麦克风、注册表或网络操作已经验证。
